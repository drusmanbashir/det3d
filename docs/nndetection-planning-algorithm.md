## What is configured, calculated, and fixed

A **plan** is a saved dictionary of dataset-specific choices; a **dataset fingerprint** is the collected statistics used to choose them. Both differ from the input configuration template.

| Source of value | Examples | How to change it |
|---|---|---|
| Hydra-composed configuration | `module`, `planner`, `model_cfg`, training, augmentation and prep settings in `/home/ub/code/nnDetection/nndet/conf/config.yaml` and `/home/ub/code/nnDetection/nndet/conf/train/v001.yaml` | Hydra combines configuration files and command-line overrides at execution. |
| Python planner constants | spacing percentile 50, anisotropy thresholds 3, 3D start/max channels 32/320, batch 4, memory target | Change planner/estimator code; standard YAML does not expose these controls. |
| Dataset-derived plan outputs | target spacing, transpose, convolution kernels and strides, patch size, class weights and anchors | Change analyzed dataset or planning method; replan to write a plan pickle. |
| Runtime overrides | `model_cfg.plan_arch_overwrites`, `model_cfg.plan_anchors_overwrites`; augmentation patch/batch overrides | Override config fields. Model construction changes do not automatically rerun preprocessing or reconcile remaining plan fields. |
| Post-training inference selection | model/ensemble suppression and score thresholds | Sweep validation predictions after training, separately from experiment planning. |

Dataset contract and commands: [official README](https://github.com/MIC-DKFZ/nnDetection/blob/main/README.md). Analysis requires modality metadata and instance labels; planning requires instance boxes. A semantic foreground mask without recoverable instance identities is insufficient.

## Spacing, orientation and normalization

| Decision | Exact rule and controlling function |
|---|---|
| Target spacing | `D3V001._target_spacing_base` in `/home/ub/code/nnDetection/nndet/planning/experiment/v001.py`: per-axis 50th spacing percentile. If worst spacing > 3 × finest other spacing **and** worst-axis median voxel count × 3 < smallest other-axis median voxel count, replace worst spacing with that axis's 10th spacing percentile, bounded just above finest other spacing when necessary. |
| Low-resolution spacing | `D3V001.determine_target_spacing`: base spacing × `2**downscale`; `downscale=1` gives × 2 for `3dlr1`, a separate processed dataset and architecture plan. Trigger and spacing are separate decisions in `plan_experiment`. |
| Axis order | `D3V001.determine_forward_backward_permutation`: largest target-spacing axis first; save forward and inverse permutations. Arrays, spacings, boxes and restoration must share this convention. |
| Resampled shape | `AbstractPlanner.plan_base_stage`: cropped shape × original spacing / target spacing for each case; per-axis median drives architecture planning. |
| Normalization scheme | `AbstractPlanner.determine_normalization`: modality names select `CT`, `CT2`, or `nonCT`. `determine_whether_to_use_mask_for_norm`: disable nonzero mask for names containing `CT`; enable for other modalities only if median crop-size ratio < 0.75. Source: `/home/ub/code/nnDetection/nndet/planning/experiment/base.py`. |
| Apply | `GenericPreprocessor.apply_process`: transpose → resample → normalize. `resample`: image order 3, segmentation order 0, all axes together. The separate-axis threshold 3 is passed to `/home/ub/code/nnDetection/nndet/preprocessing/resampling.py` but has no effect, because `force_separate_z=False` fixes separate-axis resampling to off. CT clips to dataset foreground 0.5th/99.5th percentiles and uses dataset foreground mean/std; CT2 uses the same bounds with case-specific statistics; nonCT uses case mean/std, optionally within nonzero mask. Source: `/home/ub/code/nnDetection/nndet/preprocessing/preprocessor.py`. |

## How dataset values change the plan

Percentile boundaries, rounding, memory fitting and other inputs can leave outputs unchanged despite a changed dataset measurement.

| Dataset input | Calculated value | Effect on preprocessing or model |
|---|---|---|
| Number and identity of training cases | Fingerprint aggregates discovered cases' spacing, size, intensity and box values, not just case count. | Added cases can change percentiles and plan; count alone does not set depth, width or batch. `DatasetAnalyzer.analyze_dataset` in `/home/ub/code/nnDetection/nndet/planning/analyzer.py`. |
| Class dictionary and instance counts by class | `classifier_classes` and `seg_classes` equal class count; `class_weight` derives from instance counts. | Output dimensions change. `class_weight` is saved; consumption by `RetinaUNetV001` was not found, so do not assume a loss effect. `BoxC002.process_properties` and `BoxC001.compute_class_weights` in `/home/ub/code/nnDetection/nndet/planning/architecture/boxes/c002.py` and `/home/ub/code/nnDetection/nndet/planning/architecture/boxes/base.py`. |
| Number/names of modalities; dimensionality | `in_channels` = modality count; names select normalization; `dim` comes from fingerprint. | Input channels and CT/CT2/nonCT processing change, not `start_channels`, `max_channels`, FPN or head widths. `BoxC002.process_properties` and `AbstractPlanner.determine_normalization` in `/home/ub/code/nnDetection/nndet/planning/experiment/base.py`. |
| Per-case voxel spacing | Target-spacing percentile, optional anisotropy correction, axis order, rescaled shapes/boxes. | Drives image/label resampling, patch shape, per-axis kernels/strides, stage count and anchors. Coarse axes can use kernel 1 and delayed downsampling. `D3V001._target_spacing_base`, `determine_forward_backward_permutation`, `BoxC002._plan_architecture`. |
| Cropped image shapes and crop reductions | Median resampled shape; median crop-size ratio. | Shape bounds initial patch and influences memory-fitting reductions/depth; crop ratio controls non-CT normalization masking. `AbstractPlanner.plan_base_stage`, `determine_whether_to_use_mask_for_norm`, `BoxC002._get_initial_patch_size`. |
| Lesion box dimensions and locations | Scaled/filtered box-size distribution; proxy maximum instances per patch; 99.5th-percentile original box dimensions. | Box sizes drive anchors; density affects memory estimate and potentially patch/depth; 99.5th-percentile test can trigger low-resolution plan. `BoxC002._get_scaled_boxes`, `_estimte_num_instances_per_patch`, `_plan_anchors`, `D3V001.trigger_low_res_model`. |
| Foreground voxel intensities | Sampled foreground mean/std and 0.5th/99.5th percentiles. | Changes CT clipping/normalization, not directly depth or channel widths. `get_voxels_in_foreground`, `compute_stats`, `GenericPreprocessor.normalize_ct`. |
| Any of the above | Fixed 3D defaults: `start_channels=32`, `max_channels=320`, `fpn_channels=head_channels=128`, `batch_size=4`. | Geometry/memory fitting can change stage count; channel widths and batch do not automatically adapt. `BoxC001.create_default_settings`, `BoxC002.create_default_settings`; encoder uses planned stages/channel limits in `/home/ub/code/nnDetection/nndet/arch/encoder/modular.py`. |

## Architecture, patch size and anchors

`D3V001.create_architecture_planner` instantiates `BoxC002` and `MemoryEstimatorDetection`. Parent `BoxC001.plan` in `/home/ub/code/nnDetection/nndet/planning/architecture/boxes/base.py`: initialize defaults → read fingerprint → `compute_class_weights` → fit patch/architecture to memory estimate → optimize anchors.

| Choice | Mechanism and source |
|---|---|
| Initial patch | `BoxC002._get_initial_patch_size`: inverse target spacing gives roughly physically isotropic patch; scale by `512`, clip to transposed median shape, using smaller median dimension of the two other axes. Adjust for network divisibility, then reduce for memory. |
| Depth, kernels and strides | `BoxC002._plan_architecture` → `BoxC001.plan_pool_and_conv_pool_late` → nnUNet `get_pool_and_conv_props`, using spacing, current patch, `min_feature_map_size=4`, `max_num_pool=999` from `BoxC001.create_default_settings`/`BoxC002.create_default_settings`. Anisotropic axes can use kernel 1 and delayed downsampling. `conv_kernels` length = encoder stage count; `strides` specify downsampling. Both adapt to spacing/fitting patch. |
| Decoder levels | `_plan_architecture` uses `num_decoder_level=4`, `min_decoder_level=2` from `BoxC001.create_default_settings`/`BoxC002.create_default_settings`: first level `min(max(1, num_resolutions - 4), 2)` through final resolution; potentially more than four levels. |
| Memory and final patch | Construct configured model; estimate training memory including instances per patch. At fixed 3D batch 4, if estimate does not fit, `_decrease_patch_size` reduces axis with largest patch/median-shape ratio, replans kernels/strides and repeats. `/home/ub/code/nnDetection/nndet/planning/estimator.py` defaults: `RTX2080TI` target (11,523,260,416 minus 11 MiB bytes), GPU 0, 910 MiB context, 768 MiB offset, mixed precision. Measures on actual GPU against fixed target unless estimator changes; no guarantee for different GPU/software stack. |
| Anchors | `BoxC002._get_scaled_boxes`: transpose boxes; scale each from its original spacing to target-spacing voxels. `BoxC001.filter_boxes`: strictly exclude sizes at/outside per-axis 0.5th/99.5th percentiles. `BoxC002._plan_anchors`/`BoxC001.find_anchors`: center boxes; three Nevergrad `TwoPointsDE` runs, 5,000 evaluations each, maximize mean best box–anchor intersection over union. `BoxC002.get_anchor_init`: `(4, 8, 16)` per axis, integer, minimum `1`; feature-level strides scale resulting anchor parameters. Calls CUDA. Model construction can override via `model_cfg.plan_anchors_overwrites` without rerunning search. |
| Additional low-resolution plan | `D3V001.trigger_low_res_model`: permute per-axis 99.5th-percentile sizes of stored original boxes; trigger if any exceeds full-resolution patch dimension. Compares stored voxel sizes directly with planned patch, without first rescaling to target spacing. |
| Dummy 2D augmentation | `AbstractPlanner.plan_base_stage`: set `do_dummy_2D_data_aug` if largest/smallest patch dimension > 3. Changes augmentation geometry, not model dimensionality. |

Plan fields: `target_spacing`, `target_spacing_transposed`, `transpose_forward`/`transpose_backward`, normalization/mask decisions, dataset properties, `patch_size`, `batch_size`, `architecture`, `anchors`, `data_identifier`, `do_dummy_2D_data_aug`. Retain fingerprint, plan, input configuration, dataset identity and source/dependency versions together for reproducibility. Spacing/transpose/patch-convention changes require coordinated image preprocessing, box coordinates and inference restoration.

## LIDC example and integration choices

Saved `/s/fran_storage/nndet_conf/plans/lungs/D3V001_3d.pkl`: 608 LIDC cases, target spacing `[2, 0.703125, 0.703125]`, patch `[128, 128, 64]`, six convolution stages, decoder levels `(2, 3, 4, 5)`, start/max channels `32/320`, FPN/head channels `128/128`, batch 4, `trigger_lr1=True`, `do_dummy_2D_data_aug=True`. Check each value's axis convention/permutation before comparing pipelines. Trigger flag does not prove successful low-resolution training/ensembling.

Choose the component owning the complete preprocessing/coordinate contract. To import a plan, map axis order, spacing, label classes, normalization, image/box transformations, kernels, strides, decoder levels, anchors and inference restoration into `det3d`; then verify constructed model and transformed cases against that plan. Alternatively, port selected planning rules and record differing rules/constants. Copying YAML or pointing to a pickle alone neither runs planning nor makes preprocessing pipelines equivalent. Validate proposed behavior on the same training cases and held-out cases before attributing performance changes to planning.
