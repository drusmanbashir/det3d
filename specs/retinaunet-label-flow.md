# Retina U-Net label flow

Status **Pending review.** This report traces the LIDC `sota` run and proposes where det3d should prepare segmentation targets for future runs.

## Decision

Prepare one segmentation target from the final patch immediately after box tracking and before the network step. Use that exact target for the loss, validation Dice, and W&B. For the active `DiCESegmenterFgBg` head, make it binary in one pass. Keep the detection box classes separate so a plan can detect several classes while segmenting their union. For a head that genuinely segments individual classes, produce its class indices directly in the same place.

There are two opportunities to reduce work. Remove crop-only labels once during preprocessing when the plan fixes that policy. Resolve the loss-specific target at the shared training and validation boundary so plans can reuse their existing preprocessed data. SOTA already supplies only nodule foreground to the loss. The recurring overhead is how det3d constructs that target.

## From source label map to saved data

SOTA leaves that setting blank, so the saved map still has `{0, 1, 2}`. Plan 3 used this step to map lung `1 → 0` and assign three nodule IDs. ## Inside a training or validation step

1. **Set the foreground classes once.** At setup, `infer_det_labels_from_data_folder()` reads the detection manifest and sets `fg_labels`. The nodule box ID stays `2` in the dataloader. The network adapter maps it to detection class index `0`. The segmentation loss reserves voxel value `0` for background. [Manifest reader](../det3d/managers/data/labels.py#L7) · [Detection class mapping](../det3d/managers/retinaunet.py#L149)
2. **Read the patch and move image and mask together.** SOTA picks the training crop from the box sampling metadata, reads only that crop from HDF5, pads it, and stacks patches into a batch. On the GPU it applies flip, affine, and final crop or padding to image and mask together, with nearest-neighbor interpolation for labels. `HullTracker.finalize()` then checks each surviving box for voxels matching its semantic label. For SOTA, this is a check for `lm == 2` within a box labelled `2`. Validation with `bbox_anchor` loads cases from the `.pt` files, crops and pads around the selected box, and finalizes tracking before computing loss. [Training loader](../det3d/managers/data/main.py#L520) · [GPU transforms](../det3d/transforms/gpu_det.py#L325) · [Hull check](../det3d/transforms/box_tracker.py#L174) · [Validation order](../det3d/managers/data/main.py#L607)
3. **Build the model targets.** `step_losses()` calls `det3d_batch_to_nndet()` on the final patch batch. It converts `lm` to `int64`, allocates a second full target with `zeros_like`, and scans the patch once per label in `fg_labels` to fill consecutive positive indices. For SOTA, this is `0 → 0`, `1 → 0`, `2 → 1`. The network forward pass takes the CT image. Its loss receives the boxes, detection class indices, and `target_seg`. [Batch conversion](../det3d/managers/retinaunet.py#L166) · [Network step](../det3d/managers/retinaunet.py#L222) · [nnDetection loss call](../../nnDetection/nndet/core/retina.py#L129)
4. **Make the foreground binary again.** `DiCESegmenterFgBg` rewrites every positive target value to `1` in the same tensor, then computes cross-entropy and Dice. For SOTA the values are already binary. With plan 3, the classifier can retain three nodule classes while this segmentation head still compares the union of their voxels. Validation Dice uses the resulting `target_seg`. [Binary head](../../nnDetection/nndet/arch/heads/segmenter.py#L223) · [Validation Dice](../det3d/managers/retinaunet.py#L312)
5. **Draw the W&B grid.** The current callback selects a slice from `batch["lm"]` and colors every positive voxel. That exposes the crop-only lung label in SOTA. Future train and validation grids should take their slice from the target used by the loss and retain only the slice on CPU. `full_volume` validation currently computes detection metrics without a segmentation loss, so its grid can show GT boxes alone. [Grid input](../det3d/callback/wandb_det_grid.py#L94) · [Overlay rule](../det3d/detection/visualize_image.py#L405) · [Full-volume validation](../det3d/managers/retinaunet.py#L252)

## Where to put the remaps

**For the shared training path, use the existing batch adapter.** `det3d_batch_to_nndet()` is the common point after box tracking for GPU-augmented training, item-level training, and validation paths that compute segmentation loss. Resolve the allowed foreground IDs and target encoding once when the model is configured. At each step, build the final target in one pass from the final-sized patch. For the binary head, the condition is membership in `fg_labels`. For a multi-class head, the same mapping step emits the corresponding class indices. Keep the foreground definition plan-driven. Route the resulting tensor through to loss, Dice, and the logging callback on grid steps. The binary loss can consume an already-binary target if its current in-place rebinning is removed in a future implementation.

**Memory cost.** A `256 × 192 × 96` SOTA patch has 4,718,592 voxels. A byte-wide map is 4.5 MiB and an `int64` map is 36 MiB. The current conversion can hold both a 36 MiB copy of the source labels and a 36 MiB target at the same time, plus a temporary comparison mask. Cross-entropy still consumes an `int64` target. The avoidable cost is widening the source map before lookup, rescanning for each foreground class under a binary head, and scanning again inside the binary loss. Measure peak GPU memory and step time before claiming a speedup.

**For a fixed policy, drop crop-only IDs once after `Crop` in LBD.** `remapping_lbd_rbd` is the existing place to do it, before `Stats` and before the common map is saved for `.pt` validation and HDF5 training. A SOTA-derived plan can remove lung `1 → 0` while retaining nodule ID `2` so the box labels and hull checks still agree. This removes lung from the training data's label map, while preserving its role in preprocessing. It still leaves the final `2 → 1` target conversion. To eliminate that conversion as well for a fixed single-class dataset, LBD can emit `{0, 1}` and rebuild the sidecars, manifest, and sampling metadata in that label space. Both `ignore_labels=[1]` and `fg_indices_exclude=[1]` need review at their respective stages before reusing `1` for nodules. A changed preprocessing policy belongs to a new plan ID. [LBD artifact identity](../../fran/fran/utils/folder_names.py#L67) · [Plan identity rule](../../fran/specs/configmaker/MAIN.md#L23)

**Preserve current supervision when reusing other plans.** Keep distinct semantic IDs through component extraction and tracking when the detector needs distinct classes. A box can be removed by size filtering while voxels with the same admitted semantic class remain in `lm`. The current loss can still supervise those voxels. Building the segmentation target from `inst` or from the boxes that survive a patch would change that behavior. Compare the old and proposed post-head targets voxel for voxel, and check that detection classes and boxes agree, for a SOTA-style mask, plan 3 with multiple nodule classes, and a background-only patch. Include training and `bbox_anchor` validation with `hull`. [Box filtering](../../fran/fran/transforms/bbox_stats.py#L30) · [Voxel target membership](../det3d/managers/retinaunet.py#L183)
